# Dictionary REST API

This project was made for the Web Programming 2 course. I used code examples and instructions provided by the teacher.

I made a REST API using Node.js, Express and TypeScript. The API stores Finnish and English word pairs in a text file called sanakirja.txt.

The API can search for Finnish words and return their English translations. It can also add new word pairs to the dictionary.

## Technologies
- Node.js
- TypeScript
- Express.js
- REST API

## How  to run

First install the dependencies:

npm install

Start the server:

npx tsx server.ts

The server runs at http://localhost:3000/.
